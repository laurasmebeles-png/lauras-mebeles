# WordPress eksporta sākotnējais inventārs

Saņemts 30.10.2026. Avots: laurasmbeles.WordPress.2026-10-30.xml. Oriģināla darba kopija atrodas assets/originals/ un netiek iekļauta Git.

Eksportā ir **55 publicētas lapas** un **834 pielikumu ieraksti**. Pielikumu ierakstu skaits nav tas pats, kas lejupielādēto attēlu failu skaits (vienam attēlam var būt vairākas versijas).

Publicēšanas statuss eksportā nepierāda, ka URL pašlaik darbojas vai ir Google indeksā. Esošie URL saglabāti tieši no XML; pāradresācijas vēl nav ieviestas. Nav veikta visu lapu tiešsaistes pārbaude.

## Būtiskie atradumi

- Papildus pakalpojumiem ir publikācijas par virtuvēm, veikala un komplektu lapas, privātuma politika, divas atsauksmju lapas un testēšanas lapa. Šīs adreses jāizvērtē pirms migrācijas.
- Saglabātas LV, EN un RU adreses. RU gala loma vēl nav izlemta.
- Eksportā norādītais uzņēmuma Facebook profils: https://www.facebook.com/LaurasMebeles/. Tas vēl nav šajā solī pārbaudīts tiešsaistē.
- Eksportā norādītais Instagram profils: http://www.instagram.com/lauras_mebeles_.
- JSON inventāros nav eksportēti WordPress autoru e-pasti vai pilns lapu HTML. Attachment parent_id ir tikai WordPress piesaiste; tā nepierāda, ka foto attēlo vienu mēbeļu projektu.
