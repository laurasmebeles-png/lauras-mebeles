# Avota faili

- home.html — sākumlapas avots, formas/cenu/procesa sadaļas.
- catalog.mjs — sešas pakalpojumu kategorijas, desmit atlasītie projekti un to foto.
- reviews.json — sešas īstas mājaslapas atsauksmes no saņemtā XML.

Kopīgo navigāciju un lapas ģenerē scripts/generate-pages.mjs. Pēc izmaiņām: npm run generate. HTML rezultātu public/ mapē tieši nelabot.
