# Oriģinālie materiāli

Šeit var ievietot vecā logo failus un projektu foto oriģinālus. Šīs mapes pārējie faili ir izslēgti no Git ar `.gitignore`; tiem jābūt arī atsevišķā rezerves kopijā.

Katram foto komplektam vajadzīgs projekta nosaukums, mēbeļu veids, izmēri, materiāli un atļautais apraksts. Klientu privātās adreses un kontaktinformācija nav vajadzīga publicēšanai.

Publicēšanai atlasītās un optimizētās versijas glabājam `public/images/`. Logo saglabājam pēc iespējas oriģinālajā vektoru formātā.
